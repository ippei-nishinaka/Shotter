# Shotter

macOS 用のメニューバー常駐型スクリーンショット注釈アプリ。
撮影 → 注釈 → コピー／保存 までを、キーボードから手を離さずに完結できます。

外部パッケージに一切依存せず、Apple の標準フレームワークだけで書かれています
（SwiftUI / AppKit / ScreenCaptureKit / Core Graphics / Core Image / Vision / Carbon）。

## できること

- **範囲キャプチャ**（⌃⇧A） — ドラッグで範囲を選択。撮影前に画面をフリーズさせるので、
  オーバーレイが写り込まず、前面アプリのウィンドウも非アクティブ表示になりません
- **ウィンドウキャプチャ**（⌃⇧W） — カーソル下のウィンドウを選んで撮影。選択中に Space で範囲選択と相互切替
- **文字認識**（⌃⇧O） — 選んだ範囲の日本語・英語をテキストにしてコピー
- **12 種類の注釈ツール** — 矢印 / 四角（枠・塗り）/ 円 / 線 / フリーハンド / ハイライト /
  テキスト / モザイク・ぼかし / 強調 / ナンバリング、そして描いたものを編集する編集ツール
- **撮影後のサムネイル** — クリップボードに入れつつ画面隅に 10 秒表示。クリックで注釈エディタへ
- **マルチディスプレイ対応** — ディスプレイをまたいだ範囲選択も 1 枚に合成します
- **PNG / JPEG 保存**、**自動起動**、**ホットキーのカスタマイズ**

## 動作環境

- macOS 13 (Ventura) 以降
- ビルドには Xcode か Command Line Tools が必要（**Xcode がなくてもビルドできます**）

Apple Silicon / Intel 両対応（universal binary）です。

## インストール

[Releases](https://github.com/ippei-nishinaka/Shotter/releases) から `Shotter-*.zip` をダウンロードして、
展開した `Shotter.app` を「アプリケーション」フォルダへ移動してください。

**このアプリは Apple の公証（notarization）を受けていません。**
そのままでは macOS に起動を止められるので、ターミナルで次を 1 回だけ実行してください。

```
xattr -dr com.apple.quarantine /Applications/Shotter.app
```

ターミナルを使いたくない場合は、一度アプリを開こうとしたあとに
システム設定 > プライバシーとセキュリティ の下の方に出る「このまま開く」を押しても同じです。

> 公証には Apple Developer Program（年 99 ドル）が必要なため、現状は見送っています。
> 中身が気になる場合は、下記の手順でソースから自分でビルドしてください。

## ビルドと起動

```
./build.sh run
```

| コマンド | 内容 |
| --- | --- |
| `./build.sh` | デバッグビルド |
| `./build.sh release` | リリースビルド（最適化あり） |
| `./build.sh run` | ビルドして起動 |

| `./build.sh clean` | `build/` と `dist/` を削除 |

### 公証まで行う場合

Apple Developer Program に入っている場合は、環境変数を渡すと `dist` が署名・公証・
チケットの添付までまとめて実行します。

```
export SHOTTER_DEVELOPER_ID="Developer ID Application: Your Name (TEAMID)"
export SHOTTER_NOTARY_PROFILE="shotter"   # xcrun notarytool store-credentials で作成
./build.sh dist
```

## 構成

```
Shotter/
  App/         アプリのエントリポイントと AppDelegate
  MenuBar/     メニューバー常駐（NSStatusItem）まわり
  Capture/     ScreenCaptureKit による撮影と範囲選択オーバーレイ
  Editor/      注釈編集ウィンドウ（SwiftUI ツールバー＋CG キャンバス）
    Annotations/ 注釈の種類ごとの描画実装
  UI/          HUD・権限ダイアログなどの共通 UI
  HotKey/      グローバルホットキー（Carbon RegisterEventHotKey）
  OCR/         Vision による文字認識
  Support/     座標変換・クリップボード・設定・書き出しなどのユーティリティ
  Resources/   Info.plist
build.sh       Xcode なしで .app を組み立てるビルドスクリプト
tools/         開発用スクリプト
```

## 画面収録の権限について

Shotter は macOS の「画面収録」の許可が必要です。初回起動時に案内ウィンドウが出るので、
そこから システム設定 > プライバシーとセキュリティ > 画面収録 で有効にしてください。
許可を反映するにはアプリの再起動が必要ですが、案内ウィンドウのボタンから再起動できます。

なお ad-hoc 署名だとビルドのたびに署名が変わり、この許可が毎回リセットされます。
一度だけ以下を実行して自己署名の証明書を作っておくと、許可が維持されます。

```
./tools/create-signing-identity.sh
```

## 撮影の流れ

既定では、撮影するとすぐにクリップボードへコピーされ、画面の右下に**サムネイルが 10 秒間**表示されます。
そのサムネイルをクリックすると注釈エディタが開きます。マウスを乗せている間はカウントダウンが止まります。
この挙動は 設定 > 撮影後 で「すぐに注釈エディタを開く」「コピーだけする」に変更できます。

範囲選択の最中に **Space キー**を押すと、カーソルの下にあるウィンドウをその場で撮影します。
ウィンドウキャプチャ（⌃⇧W）では、カーソルの下のウィンドウが明るく表示され、
クリックまたは Space で撮影します。

ウィンドウを撮ったときは**四隅を透明にくり抜く**ので、角に背景が写り込みません。
`SCContentFilter(desktopIndependentWindow:)` が返すウィンドウのアルファをそのままマスクに使うため、
角丸の半径を決め打ちする必要がなく、OS のバージョンが変わっても正しい形になります
（macOS 26 で角丸が 10pt から約 20pt に変わっています）。

## 影を付ける

エディタのツールバーの影ボタン、または **S キー**で、画像の周りに余白と影を付けられます。
資料やブログにウィンドウのスクリーンショットを貼るときに見栄えがします。

- 影は元画像のアルファに沿って落ちるので、**ウィンドウの角丸に沿った自然な影**になります
- 注釈には影が付きません（画像だけに落ちます）
- 背景は透明のまま出力されるので、貼り付け先の背景色になじみます
- 注釈の座標系には影響しません。オン／オフをいつ切り替えても、描いた注釈の位置はずれません
- 設定は記憶され、次に撮ったときも同じ状態になります

## 文字認識（OCR）

Vision の `VNRecognizeTextRequest` を使い、**日本語と英語**を認識します。使い方は 2 通りです。

- メニューバー 📷 →「文字を読み取ってコピー」または **⌃⇧O** — 範囲を選ぶとテキストが直接クリップボードへ入ります
- 注釈エディタのツールバーの 🔍 ボタン — 認識結果をシートで表示し、編集してからコピーできます

認識は注釈を含まない元画像に対して行うので、描いた矢印や文字が誤認識されることはありません。

## 自動起動

設定 > 起動 > 「Mac の起動時に Shotter を自動起動する」で有効にできます。
`~/Library/LaunchAgents/com.ippei.Shotter.launchatlogin.plist` を作る方式です
（`SMAppService` は自己署名ビルドでは使えないため）。
**アプリを別の場所へ移動したら、設定画面の「今の場所に更新」を押してください。**

## グローバルホットキー

| ホットキー | 動作 |
| --- | --- |
| ⌃⇧A | 範囲を選択してキャプチャ |
| ⌃⇧W | ウィンドウを選択してキャプチャ |
| ⌃⇧O | 範囲を選んで文字を読み取り、テキストをコピー |

macOS 標準のスクリーンショット（⌘⇧3 / 4 / 5）と競合しないキーを既定にしています。
どちらもメニューバー > 設定… から変更できます。Carbon の `RegisterEventHotKey` を使っているため、アクセシビリティ権限は不要です。

## エディタのキーボードショートカット

ショートカットは**英語名の頭文字**です。ツールバーのアイコンにマウスを乗せると、
できることとショートカットが**即座に**ツールチップで出ます
（SwiftUI 標準の `.help()` は表示まで約 1 秒かかり、無効状態のボタンでは出ないため、
[InstantTooltip.swift](Shotter/Editor/InstantTooltip.swift) で自前実装しています）。

| キー | ツール | 英語名 |
| --- | --- | --- |
| E | 編集（描いた注釈を選ぶモード） | **E**dit |
| A | 矢印 | **A**rrow |
| R | 四角（枠） | **R**ectangle |
| B | 四角（塗り） | **B**lock |
| C | 円 | **C**ircle |
| L | 線 | **L**ine |
| D | フリーハンド | **D**raw |
| H | ハイライト（蛍光ペン） | **H**ighlight |
| T | テキスト | **T**ext |
| M | モザイク／ぼかし | **M**osaic |
| F | 強調（範囲外を暗くする） | **F**ocus |
| N | ナンバリング（自動採番の丸数字） | **N**umbering |

| キー | 操作 |
| --- | --- |
| S | 影（**S**hadow）のオン／オフ |
| ⌃Z / ⌘Z | 元に戻す |
| ⌃Y / ⌃⇧Z / ⇧⌘Z | やり直す |
| Delete | 選択中の注釈を削除 |
| Esc | 選択を解除 |
| ⌘C | 注釈込みでクリップボードにコピー（テキスト入力中は文字のコピー） |
| ⌘S | PNG / JPEG で保存 |

Shift を押しながらドラッグすると、線・矢印は 45 度刻み、四角・円・モザイク・強調は正方形に固定されます。

編集ツール（E）では、編集ツール（E）では、注釈をクリックして選択・ドラッグで移動・つまみでリサイズ・Delete で削除できます。
テキストはダブルクリックで再編集、Esc で選択解除です。
